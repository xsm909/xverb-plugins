# SFTP: changes

## 0.1.0 — 2026-09-25

- Browse, read, write, rename and delete over SFTP, through the machine's own ssh.
- Keys, the agent and ~/.ssh/config work as they do in a terminal; a password is handed to ssh when it asks.
- A file arrives with its own date, and a cancelled copy leaves nothing half-written behind.
- A copy from one place on a server to another is done by the server, where it can.
